## 📝 学習メモ

### 第1章 コレクションとジェネリクス
- **PECS の原則**
  - 戻り値（Producer）: `extends` を使う
  - 引数（Consumer）: `super` を使う
- **Comparable**: 比較可能なオブジェクトを表す。抽象メソッドは `compareTo`（引数1つ）
- **Comparator**: 並べ替え方法を定義する。抽象メソッドは `compare`（引数2つ）

### 第2章 関数型インタフェースとラムダ式
- **ラムダ式で中カッコを省略した場合**
  - 処理は1文だけ記載できる
  - `return` は記載できない（省略必須）
- **ラムダ式で中カッコを省略しない場合**
  - `return` は省略できない
